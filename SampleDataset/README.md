# Sample Answer Sheets Dataset

This directory contains representative single-page PDF answer sheets used for testing and validating the AutoChecker evaluation pipeline (text line segmentation, OCR, sentence embeddings, and diagram visual similarity).

## Dataset Privacy & Governance (ML-DATA-02)

To comply with academic data protection best practices and student privacy standards:

1. **De-Identification**: All sample answer sheets included in this repository are anonymized or synthetic test papers. No real student identifying information (such as personal names, roll numbers, student email addresses, or university identification numbers) is included.
2. **Acceptable Content**: When contributing or updating test sheets in this folder, ensure that:
   - Header metadata (e.g. name, seat number, exam center) is masked, cropped, or sanitized prior to PDF generation.
   - Files contain only coursework answers, problem statements, and hand-drawn technical diagrams.
3. **Usage**: These files are intended exclusively for local offline testing, automated CI validation, and benchmarking model scoring thresholds.
